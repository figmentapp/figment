# Vignette

The node renders a vignette on the input image.

## Parameters

- **Radius**: The radius of the clear area, from 0 to 1.
- **Center X**: The horizontal location of the vignette.
- **Center Y**: The vertical location of the vignette.
- **Strength**: How dark the edges get, from 0 (no vignette) to 1.
- **Softness**: The width of the transition between the clear area and the edges.
- **Color**: The color of the vignette. Black by default.
