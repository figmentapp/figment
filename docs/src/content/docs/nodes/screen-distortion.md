# Screen Distortion

Bulge the image like the glass of an old monitor and, optionally, draw a grid of dark lines over it.

## Parameters

- **Distortion** How much the image bulges, from 0 to 1.5.
- **Lines** `On` draws the grid, `Off` leaves only the bulge.
