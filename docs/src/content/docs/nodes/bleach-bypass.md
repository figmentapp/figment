# Bleach Bypass

Imitate the film-lab process of skipping the bleach bath: high contrast, low saturation, and a silvery look in the highlights.

## Parameters

- **Opacity** How much of the effect is mixed in, from 0 to 2. `0` passes the image through, `1` is the full effect, and values above `1` push the contrast further.
