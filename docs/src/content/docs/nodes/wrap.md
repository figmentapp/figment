# Wrap

Bend the image into a circle. The left and right edges meet at the center, and the top and bottom edges become the rim.

## Parameters

- **Radius** The size of the circle, from 0 to 5. Values above `1` show the image more than once around the rim.
- **Twist** Spirals the image around the center, from -1 to 1.
