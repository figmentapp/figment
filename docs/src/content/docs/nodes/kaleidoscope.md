# Kaleidoscope

Mirror a wedge of the image around its center, so the whole frame becomes a symmetric pattern.

## Parameters

- **Angle** Rotates the wedge, in radians from 0 to 6.3. Bind it to an expression such as `$TIME` to make the pattern turn.
- **Sides** The number of mirrored wedges, from 0 to 35.
