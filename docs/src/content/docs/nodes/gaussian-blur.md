# Gaussian Blur

Blur the image with a small Gaussian kernel. It is cheap, so use it for a light soften or as a step in a bigger effect. For strong blurs, [Blur](/docs/nodes/blur) is the better choice.

## Parameters

- **Factor** The width of the blur in pixels, from 0 to 5. `0` passes the image through.
