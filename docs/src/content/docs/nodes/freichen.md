# Freichen

Find the edges in the image with the Frei-Chen operator. Compared to [Sobel](/docs/nodes/sobel), it responds more evenly to edges in every direction and gives thinner lines.

## Parameters

- **Resolution** The pixel grid the operator samples on, from 4 to 2048. Set it to the size of the input image for the sharpest edges; a lower value gives thicker, softer edges.
