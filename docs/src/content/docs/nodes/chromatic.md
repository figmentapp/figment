# Chromatic

Add chromatic aberration: the red, green, and blue channels shift apart towards the edges of the image, the way a cheap lens splits colors. The node also bends the image slightly and darkens the corners, like a curved screen.

## Parameters

- **Factor** How far the channels drift apart at the edges, from 0 to 0.2.
