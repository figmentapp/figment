# Solarize

Invert every color channel that is brighter than the threshold, the way an over-exposed print flips its highlights.

## Parameters

- **Threshold** The brightness above which a channel inverts, from 0 to 1.5. At `0` the whole image inverts; at `1` or above nothing changes.
